# 网页文字版文明游戏 · 项目复盘

## 项目介绍

这是一个使用 Node.js 开发的网页文字版《文明》游戏。玩家通过文本界面体验最基础的文明玩法，项目不追求炫酷特效，重点验证核心游戏循环与 AI 辅助开发流程。

## 开发方法

使用 **DeepSeek Harness 最新版** 开发，核心提示词为：

1. “用 NodeJS 做一个文字版的文明游戏，不需要炫酷的特效。”
    
2. “实际上我希望可以做一个网页端的文字游戏，实现最基础的功能，代码行数限制在 1 万行以内。”

## 项目反思

应该先具体规划好项目，再交给 AI 完成。  
如果没有明确的功能范围、模块拆分和验收标准，AI 容易生成大量需要返工的内容，从而浪费时间和 API 成本。

## 一句话总结

用 DeepSeek Harness 在约 16 分钟内、以 ¥3.1983 的 API 成本，完成了一个 Node.js 网页文字版文明游戏原型：基本玩法实现，AI 测试通过；核心教训是——**AI 开发前必须先做规划**。
