什么是 Rustlings

Rustlings 是由 Rust 官方维护的交互式学习项目。它的玩法很朴素：给你一段编译不过或测试不过的代码，你把它改对，就算过关。通过这种「修好它」的循环，逐步熟悉语法、类型系统，以及 Rust 最特别的所有权机制。

安装与初始化

  1. 先更新工具链，避免版本不一致带来的奇怪问题：

    rustup update

  2. 安装 rustlings：

    cargo install rustlings

  3. 在代码目录中初始化练习，会生成一个 rustlings/ 文件夹：

    rustlings init

  4. 进入练习目录并启动，修改文件后会自动检测结果：

    cd rustlings
rustlings

常用命令

记住这四条就够日常使用了：

rustlings list              # 查看所有练习和进度
rustlings run variables1    # 单独运行某个练习
rustlings hint variables1   # 查看提示
rustlings reset variables1  # 重置某个练习

今日易错点

💡
五个反复踩到的坑
  • 变量默认不可变，需要修改时必须加 mut。
  • 函数返回值不能随意加分号，加了分号就变成了返回 ()。
  • if 的条件必须是 bool，不能像 Python 那样依赖 truthy / falsy。
  • 数组类型是 [T; N]，长度固定；切片 &[T] 是对数组或 Vec 的借用视图。
  • char 用单引号，是 Unicode 标量；字符串字面量 &str 用双引号。
