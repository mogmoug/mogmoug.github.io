用 16 分钟做一款文字版文明：Civtext 项目复盘

2026-09-24 约 5 分钟 civtext · nodejs · 项目复盘
🏛️
项目速览

一个用 Node.js + 原生前端做的网页文字版《文明》。没有炫酷特效，只有字符地图、数字和决策。 总耗时约 16 分钟，API 成本 ¥3.1983，基本玩法跑通。

项目介绍

这是一个使用 Node.js 开发的网页文字版《文明》游戏。玩家通过文本界面体验最基础的文明玩法： 造单位、扩张、决策。项目不追求炫酷特效，重点验证核心游戏循环，以及 AI 辅助开发的完整流程。

开发方法

使用 DeepSeek Harness 最新版开发，核心提示词只有两句：

「用 NodeJS 做一个文字版的文明游戏，不需要炫酷的特效。」

「实际上我希望可以做一个网页端的文字游戏，实现最基础的功能，代码行数限制在 1 万行以内。」

第一句给了方向，第二句补上了形态和边界。边界这一点很关键——「1 万行以内」和「网页端」 把范围收窄之后，AI 才不至于漫无目的地发挥。

完成情况

  • 基本游戏玩法已实现，可以正常开局和推进回合。
  • AI 算法测试通过。
  • 没有做额外的美术、音效与存档系统——这是刻意的取舍。

项目反思

应该先具体规划好项目，再交给 AI 完成。如果没有明确的功能范围、模块拆分和验收标准， AI 很容易生成大量需要返工的内容，从而浪费时间和 API 成本。

🧭
如果重来一次

先写一页纸的需求：核心循环、数据结构、界面分区、验收清单；再把任务拆成小步， 让 AI 一次只改一个模块。这样即使方向错了，返工成本也可控。

一句话总结

用 DeepSeek Harness 在约 16 分钟内、以 ¥3.1983 的 API 成本，完成了一个 Node.js 网页文字版文明游戏原型： 基本玩法实现，AI 测试通过；核心教训是——AI 开发前必须先做规划。
