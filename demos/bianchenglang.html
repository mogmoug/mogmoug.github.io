🌿 自然语言编程语法

这是一个图灵完备的中文编程语言。所有语句使用自然语言风格，关键字之间用空格分隔。

📌 变量赋值

  • 设 x 为 5
  • 让 y 等于 10

📌 输出

  • 打印 x
  • 输出 "你好，世界"

📌 算术运算

  • 加 减 乘 除以
  • 例：x 加 y 乘 2（乘除优先于加减）
  • 可用括号：(x 加 y) 乘 2

📌 条件判断

  • 如果 条件 那么 ... 否则 ... 结束
  • 支持 否则如果

📌 循环

  • 当 条件 循环 ... 结束
  • 重复 次数 次 ... 结束

📌 函数定义（支持递归）

  • 定义 函数名 接收 参数1 参数2 ... 结束
  • 调用：调用 函数名 使用 参数1 参数2
  • 返回值：返回 表达式

📌 列表

  • 创建：设 列表 为 [1, 2, 3] 或 空列表
  • 访问：列表 的 第 0 项
  • 长度：列表 的 长度
  • 添加：向 列表 添加 4

📌 比较运算

  • 大于 小于 等于
  • 大于等于 小于等于 不等于

📌 逻辑运算

  • 并且 或者 非

📌 注释

  • 以 # 或 // 开头
