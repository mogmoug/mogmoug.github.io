化学实验室操作指南LAB MANUAL
01界面与基本操作
  • 添加药品：在左侧药品架点击某药品（拿起后鼠标旁出现标签），再点击实验台上的任意容器即可加入。液体每次加入 5.0 mL，固体每次加入 1.0 g（一药匙）。按 Esc 放下。
  • 移动器材：所有器材（烧杯、试管、酒精灯、铁架台装置等）均可直接拖动。
  • 倾倒：把一个容器拖动到另一个容器上松开，即可将液体倒入对方（沉淀保留在原容器）。
  • 胶头滴管：点击滴管将其拿起，先点某容器吸液，再点另一容器滴加（每次约 0.5 mL），适合滴定终点控制。
  • 玻璃棒：拿起后点击容器，搅拌 5 秒——可加快反应速率与溶解。
  • 加热：点击酒精灯点燃/熄灭；把试管、烧杯拖到火焰上方即可加热（温度计可测温）。
  • 导管连接：拿起橡胶导管，先后点击两个容器，即可把气体从前者导入后者（如 CO₂ 通入石灰水）；点击导管可拆除。
  • 过滤：把漏斗放到某容器正上方会自动对接；将含沉淀的混合液倒入漏斗即完成过滤。
  • 点燃/检验气体：用火柴点击容器/集气瓶点燃气体；用带火星的木条点击集气瓶检验氧气。
  • 不需要的器材拖入右下角 🗑 移除；Delete 删除选中项。
02演示实验一 · 酸碱中和反应（NaOH + HCl）
HCl + NaOH = NaCl + H₂O　（放热反应，ΔH ≈ −57 kJ·mol⁻¹）
  1. 点击模板「酸碱中和滴定」，或：在烧杯中加入 NaOH 溶液（约 3 次），再滴加 酚酞试液 → 溶液变红色。
  2. 点击胶头滴管，先点「稀盐酸」所在……——更简单：拿起滴管后点击烧杯旁的盐酸临时杯（可先用试管装 5 mL 稀盐酸），吸满盐酸。
  3. 用滴管逐滴向烧杯中滴加稀盐酸，同时用玻璃棒搅拌，观察右侧温度曲线上升、pH 下降。
  4. 当溶液红色恰好褪去（pH≈8.2 以下）即为滴定终点，此时酸碱恰好完全反应；继续滴加溶液呈酸性（石蕊可变红验证）。
观察数据：右侧面板实时显示 NaOH、HCl 的物质的量与浓度、温度和反应速率；换成 H₂SO₄ + NaOH、稀硫酸 + 石灰水同样成立。
03演示实验二 · 高锰酸钾制取氧气（初中全套装置）
2KMnO₄ ＝△＝ K₂MnO₄ + MnO₂ + O₂↑
  1. 点击模板「高锰酸钾制氧气」：出现铁架台 + 试管夹 + 略向下倾斜的试管 + 导管 + 水槽 + 集气瓶（排水法）全套装置。
  2. 在药品架点击 高锰酸钾，再点击装置的试管部位，加入约 3 g（3 次）。试管口已自动放置一团棉花，防止粉末进入导管。
  3. 把酒精灯拖到试管下方虚线标记处，点击点燃。先移动火焰位置相当于"预热"，随后集中加热。
  4. 温度超过约 200 ℃ 后反应开始：水槽中导管口出现气泡，集气瓶内水被排出——当瓶口有大气泡冒出即已集满。
  5. 点击集气瓶将其在水下盖好玻璃片取出（正放于桌面，因 O₂ 密度略大于空气）。
  6. 用带火星的木条点击集气瓶口 → 木条复燃，证明是氧气。
  7. 结束实验：必须先点击 「移出导管」，再点击 「熄灭酒精灯」！
⚠ 若先熄灭酒精灯，试管内气压下降，水槽中的水会倒吸进入灼热试管，导致试管炸裂（本模拟器会真实演示该事故）。
04拓展实验速查
2H₂O₂ =MnO₂= 2H₂O + O₂↑　——加入 MnO₂ 催化剂对比速率；加热或改用 30% 双氧水观察速率剧增（可能喷溅！）
CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑　——用导管把 CO₂ 通入澄清石灰水：Ca(OH)₂ + CO₂ = CaCO₃↓ + H₂O（变浑浊），继续通入又变澄清
Zn / Mg + 稀H₂SO₄ 或稀HCl → H₂↑　——用火柴点燃氢气会"爆鸣"；对比稀盐酸与浓盐酸的速率差异
Fe + CuSO₄ = FeSO₄ + Cu　——铁钉表面析出红色铜，蓝色溶液变浅绿
CuSO₄ + 2NaOH = Cu(OH)₂↓ + Na₂SO₄　｜　AgNO₃ + NaCl = AgCl↓ + NaNO₃　｜　BaCl₂ + H₂SO₄ = BaSO₄↓ + 2HCl
NaOH 固体溶于水放热、NH₄NO₃ 固体溶于水吸热——直接观察温度曲线
NaOH + NH₄Cl =△= NaCl + NH₃↑ + H₂O（需加热，产生刺激性气体）

曲线图同时绘制 温度 与 反应速率 随时间的变化；选中制氧装置时绘制 试管温度 与 已收集氧气体积。
探究温度/浓度的影响：取两支试管各加 5 mL 3% H₂O₂ 与少量 MnO₂，一支加热——对比两条速率曲线；或用等量锌粒分别与 1 mol/L、12 mol/L 盐酸反应对比。
06安全须知（模拟警示）
  • 量筒不可作反应容器（模拟器会阻止其中反应）。
  • 镁与浓盐酸、高浓度双氧水遇催化剂等剧烈反应会爆炸/喷溅，请佩戴"护目镜"认真观察。
  • 点燃可燃性气体（H₂）前务必验纯，本模拟器点燃即演示爆鸣。
  • 加热固体制气结束时"先撤导管后撤灯"，防止倒吸炸裂。
