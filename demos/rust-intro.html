01什么是 Rust

Rust 是一门由 Mozilla 发起、2015 年发布 1.0 的通用系统编程语言，现由 Rust 基金会维护。 它最大的特点，是把内存管理的责任从运行时交给编译器：通过所有权、借用和生命周期规则， 在编译期就发现悬垂引用与数据竞争，因此不需要垃圾回收也能保证内存安全。 同时它拥有零成本抽象、泛型与 trait、模式匹配以及完善的包管理器 Cargo， 兼顾了 C 的性能与高级语言的开发体验。 

fn main() {
    let msg = "Hello, Rust!";
    println!("{}", msg);  // 打印到标准输出
}

02三大核心优势

⚡ 高性能

直接编译为原生机器码，没有虚拟机、没有 GC 停顿，性能与 C / C++ 处于同一量级。

🛡 内存安全

所有权与借用检查在编译期消除空指针、缓冲区溢出、悬垂引用与重复释放。

🔀 无畏并发

Send / Sync 标记让数据竞争在编译期直接报错，而不是在线上环境随机崩溃。

这三者通常互相冲突：安全要加运行时开销，性能要放弃检查。Rust 的答案是——把检查全部前移到编译期。

03所有权 Ownership

  • 每个值有且只有一个所有者变量。
  • 所有者离开作用域时，值自动释放（调用 drop）。
  • 赋值或传参默认发生移动（move），而不是浅拷贝。
  • 需要复制就用 .clone()，需要共享就用引用。
fn main() {
    let s = String::from("hello");
    let t = s;              // 所有权从 s 移动到 t
    println!("{}", t);      // ✅ 正常
    // println!("{}", s);   // ❌ 编译错误：s 已被移动
}

04借用与生命周期

fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
  • &T 是不可变借用，&mut T 是可变借用。
  • 同一作用域内：要么有任意多个不可变借用，要么只有一个可变借用。
  • 可变借用是独占访问，从规则上杜绝数据竞争。
  • 生命周期参数 'a 描述引用的有效范围，借用检查器保证引用不会比数据活得更久。

05错误处理：没有异常

Rust 没有 try / catch。可恢复的错误用 Result<T, E> 表示， 可能为空的值用 Option<T> 表示。 两者都是普通枚举，必须显式处理。

? 运算符会把错误自动向上传播， 让“正常路径”和“错误路径”在代码里同样清晰可读。 

fn read_config() -> Result<String, std::io::Error> {
    let s = std::fs::read_to_string("config.toml")?;
    Ok(s)
}

06枚举与模式匹配

enum Shape {
    Circle(f64),
    Rect(f64, f64),
}

fn area(s: &Shape) -> f64 {
    match s {
        Shape::Circle(r) => 3.14159 * r * r,
        Shape::Rect(w, h) => w * h,
    }
}

match 必须穷尽所有分支——漏掉任何一种情况，编译器就会直接报错。这让“忘记处理某个状态”这类 bug 在编译期就消失。

  • Cargo：统一的构建、依赖管理、测试与发布工具。
  • rustfmt：官方代码格式化，团队风格零争论。
  • clippy：静态检查，给出更地道的写法建议。
  • rust-analyzer：IDE 补全与内联错误提示。
  • rustup：一条命令切换稳定版 / 测试版工具链。

08它被用在哪里

系统与内核

Linux 内核、Windows、Android 均已引入 Rust 组件；Firefox 的渲染引擎大量使用。

云原生与后端

Tokio 异步运行时、高性能网关、数据库与分布式存储的常见选择。

WebAssembly

wasm-bindgen、SWC、Turbopack 等前端工具链，把原生性能带进浏览器。

嵌入式与更多

嵌入式 / 物联网、区块链、命令行工具、游戏引擎与科学计算。

09总结

Rust 用编译期的严格检查，换取运行时的安全与性能。 上手曲线确实较陡——所有权、借用、生命周期需要一些时间适应； 但一旦跨过这道坎，你会得到一门可以安心重构、放心并发的语言。

把痛苦留在编译期，而不是留在凌晨三点的线上事故里。
